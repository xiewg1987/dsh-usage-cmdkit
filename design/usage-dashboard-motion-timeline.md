# USAGE DASHBOARD — 入场动画时间轴

DeepSeek Web 本地 token 遥测插件 · 四个分辨率版共用同一套动效语言
Figma 页面：`Hero Image / usage-dashboard`（帧名 `usage-dash-360x800` / `400x520` / `720x420` / `1280x720`）

---

## 0. 共用动效契约

| 项 | 规格 |
| --- | --- |
| 入场总时长 | 0.86s（B）～ 1.18s（D），全部落在 0.8–1.2s 区间 |
| 主缓动 | `cubic-bezier(0.22, 1, 0.36, 1)`（ease-out quint），用于位置/缩放 |
| 次缓动 | `cubic-bezier(0.4, 0, 0.2, 1)`，用于纯淡入淡出 |
| 计数数字 | 线性偏 ease-out 的阶梯跳变，每档 45–75ms，末两档缩短以制造"落定"感 |
| 弧段描出 | 沿 12 点方向顺时针，每段 `stroke-dashoffset` 从满长收到 0，段间错峰 40–60ms |
| 条形生长 | 宽度从 0 生长到目标值（左端锚定），条比行名晚 60ms 起步 |
| 入场结束后 | **几乎静止**。唯一允许的持续动效：环心能量核 2–3% 亮度呼吸，周期 4.8–5.0s，ease-in-out |
| 静帧定义 | **入场结束态**。四张交付 PNG 均为该状态 |

**入场顺序铁律**（四版一致）：
`网格/角标先亮 → 列表或条错峰生长 → 主环弧段描出 → 中心数字从 0 跳到 742.6K → 洞察最后淡入`

**禁止项**（已在四版中全部规避）：粒子雪、闪字、雷达狂转、头骨/城市拼贴、满屏星点准星、MISSION/60FPS 刷屏、标题紫蓝硬渐变。

## 1. 版 A — `usage-dash-360x800`（侧栏竖条）｜ 总时长 1.06s

纵构图、无分栏。动态重点在**环弧 + 中心数字**。

| 时间 (ms) | 动作 | 缓动 |
| --- | --- | --- |
| 0 – 120 | 淡网格由 0 淡入；四角细角标依次描亮（每角 80ms） | ease-out |
| 100 – 200 | 标题 `USAGE` 淡入 + 上浮 6px→0；副题 `Local token telemetry…` 延迟 40ms 淡入 | ease-out |
| 170 – 430 | 底部四行列表**错峰生长**，行间隔 70ms：色点亮起(120ms) → 行名淡入(140ms) → 右侧 % 计数(180ms) | ease-out |
| 400 – 720 | **主环**：底环轨道 400–460 显形 → 四段弧依次描出<br>蓝 420–600 · 绿 470–640 · 紫 520–680 · 橙 560–710（每段 180ms，间隔 50ms） | ease-out |
| 560 – 820 | 环心 `742.6K` **从 0 跳到 742.6K**（每 70ms 一档，末两档 45ms），同时 scale 1.05→1 | ease-out |
| 700 – 860 | 环心副文案 `TOKENS · LAST 30 DAYS` / `DAILY AVG 24.8K · ~12% VS PREV PERIOD` 两行淡入 | ease-out |
| 700 – 880 | 环外四个彩色短标签 `38% / 28% / 22% / 12%` 淡入，同时沿各自半径外移 4px | ease-out |
| 880 – 960 | 脚注两行 + 底状态带微标淡入 | ease-out |
| 940 – 1060 | **洞察两行最后淡入**（第二行延迟 60ms，透明度 0→0.78） | ease-out |
| 1060 → | 静止。能量核 3% 亮度呼吸，周期 4.8s | ease-in-out |

## 2. 版 B — `usage-dash-400x520`（侧栏卡片）｜ 总时长 0.86s

偏方竖卡。**条与环错峰同步入场**：条比环晚起步，两者节奏并行。

| 时间 (ms) | 动作 | 缓动 |
| --- | --- | --- |
| 0 – 110 | 淡网格 + 四角角标淡入点亮 | ease-out |
| 90 – 190 | 标题 `USAGE` 与一行副标题淡入（上浮 5px→0） | ease-out |
| 170 – 460 | **主环**：底环 170–220 显形 → 四段弧<br>蓝 190–360 · 绿 235–395 · 紫 280–430 · 橙 320–460（每段 170ms，间隔 45ms） | ease-out |
| 220 – 520 | **四条进度条错峰生长**（与环并行、落后半拍）：<br>条1 220–420 · 条2 260–450 · 条3 300–490 · 条4 340–520<br>每条起始后 60ms，对应行名与 % 淡入 | ease-out |
| 420 – 640 | 环心 `742.6K` 计数 0→742.6K（每 65ms 一档，末两档 45ms） | ease-out |
| 560 – 720 | 环心两行副文案淡入 | ease-out |
| 720 – 860 | 页脚一行极小字 `DSH · WEB-LOCAL · V0.1.0 · JSON-LOCAL · HARNESS V2026.10` 淡入 | ease-out |
| 860 → | 静止。能量核 3% 呼吸，周期 4.8s | ease-in-out |

> 本版无洞察行（构图密度所限），因此"洞察最后淡入"环节整体省略。

| 时间 (ms) | 动作 | 缓动 |

| 维度 | 规格（四版统一） |

| 底色 | `#07090f` |

| 四桶色 | 未缓存输入 `#4c8dff` · 输出 `#22c55e` · 缓存读取 `#a855f7` · 缓存写入 `#f59e0b`（只出现在环段、进度条及其文字上） |
