# v7 · 视觉重设计方向（草案）

> 背景：v6 是「暗色金融终端 + 蓝青单色 + 三屏 Tab + 卡片堆叠」。
> 若你觉得**吵、密、像 crypto 壳、和 DSH 主界面脱节**，v7 按下面方向在 FigCraft 里重搭一版，再回写 `usage-theme.ts` / 视图。
>
> 工具链：`FigCraft`（ArtCraft Launcher）+ `figcraft-cli mcp`；成图仍建议从
> `render-preview.mjs` 导出对照（脚本在本地 `design/_v6_src/`，不入库）。

---

## 0. 一句话

**系统设置式的 calm：少装饰、少 Tab、一列读完；用量是「列表 + 一条主趋势」，不是仪表墙。**

---

## 1. 相对 v6 要改什么

| v6 现状（常见不满点） | v7 意图 |
|---|---|
| 近黑底 + 半透明卡 + 大量 9px 大写标签 | 与 DSH 右栏更接近的中性底（`#0f1419` 或浅灰 `#f3f4f6` 二选一），**16px 正文级**标签，减少 ALL CAPS |
| 三屏 Tab（总览 / Top / 告警）+ 头固定 | **单屏滚动** 或 **两段 Segmented**（「用量 / 明细」）；告警收成可折叠「提示」区 |
| 窄栏：大数 + 表盘 + 双 stat + 四行 + 洞察 | **一行 Hero 数字** + **一条 30 日折线** + **分组列表**（按模型），去掉表盘与洞察卡 |
| 四桶四色相 / 四档 cyan 条 | **一条堆叠水平条**（四桶占比）+ 列表行只留 **一个 4px 色点** |
| 宽栏：大环 + 双列卡 | **左窄环或条形** + **右列表**；卡片从 6 张减到 **2 张** |
| 底栏包名 + 长状态串 | **一行**：状态点 + 更新时间 + 刷新/清空（窄栏仍不重复包名） |

功能不砍：窗口切换、Top 明细、告警推导、节律——只改**信息架构与视觉密度**。

## 3. 窄栏 360×800 线框（FigCraft 帧名建议）

`v7 · Compact 360×800`

**亚克力（FigCraft）**：主内容区用半透明填 `#FFFFFF12`–`#FFFFFF18` + 内描边 `#FFFFFF1F`；效果叠 **Glass**（frost 4–6）+ **Background blur**（12–20）。底层放低饱和色块（蓝/灰椭圆）以便磨砂有东西可「透」。实现稿见 `design/dsh-meters-v7.figcraft`。

1. **Header 48** — 标题「用量」+ 窗口 Segmented（今日 / 7日 / 30日）
2. **Hero 88** — 总 tokens（32px）+ 副行「日均 xxx」
3. **Spark 56** — 全宽折线（无面积渐变）
4. **Stack bar 12** — 四桶堆叠条
5. **List** — 4 行四桶明细（点 + 名 + 值 + %）
6. **Section「模型」** — 最多 5 行 + 「查看全部」链到原 Top 逻辑
7. **Section「提示」** — 0–3 条告警，无则折叠
8. **Footer 40** — 点 + 更新于 + 按钮
