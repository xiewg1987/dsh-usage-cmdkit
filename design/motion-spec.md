# DSH CmdKit 动效说明

**适用对象**：Usage 侧栏（右栏 Tab） + Commands 命令面板（⌘K）
**对应设计稿**：`design/` 下 v4 四档静帧
**气质**：克制科幻 HUD · 流畅短促 · 可读优先
**用途**：设计出图、动效制作、代码实现的共同基准

---

## 0. 总原则

1. **一次编排，之后静止**。首次进入做一轮完整入场编排；此后界面基本静止，不循环跑动画。
2. **静止期只允许两处微动**：
   - 环心外柔光极慢呼吸（周期 3–5s，亮度变化不超过 ±5%）
   - 底部状态点的 `synced` 指示极慢闪烁（周期 ≥2s）或直接常亮
3. **可读优先**。任何动画不得让读数在运动中无法辨认；数字滚动、进度条生长都必须停在清晰可读的终值上。
4. **动效只服务于两件事**：告诉用户「东西从哪来」，以及「你刚才那一下生效了」。

---

## 1. 通用规范

| 项 | 规格 |
|---|---|
| 整段入场时长 | 0.8–1.2s（宽版 ≈1.15s，紧凑版 ≈1.0s） |
| 单元素时长 | 120–280ms |
| 退出时长 | 比进入略快（约为进入的 0.8 倍） |
| 主缓动 | 缓出（cubic-bezier 0.22, 1, 0.36, 1） |
| 次缓动 | 线性（仅用于进度条宽度、环弧生长、sparkline 描线） |
| 错峰间隔 | 每项 40–70ms；**同屏连续跳动的元素不超过 8 项** |
| 位移幅度 | 入场统一 6–10px（列表行 8px，顶部控件 6px） |

## 2. Usage 侧栏｜首次入场

### 2.1 宽版（720×420 / 1280×720）

总时长 ≈1.15s，**定格点：1.15s**。

| 时间 | 元素 | 变化 |
|------|------|------|
| 0.00s | 外框 + 四角角标 | 透明度 0→1；同时整体缩放 0.98→1.00（200ms，缓出） |
| 0.08s | 品牌头（DSH CmdKit / Usage · Commands）、顶栏 ⌘K 芯片、左列标题「Usage」与其切换器 | 三处各自上移 6px→0 + 淡入（180ms，彼此错峰 40ms） |
| 0.15s | 主视图 Tab（OVERVIEW / COST / TOP / ALERTS） | 下划线自左端生长至满宽（240ms）；文字淡入 |
| 0.20s | 时间窗药丸（TODAY / 7 DAYS / 30 DAYS） | 上移 8px→0 + 淡入（200ms） |
| 0.28s | KPI 左（CACHE HIT RATE） | 上浮 8px→0 + 淡入（180ms） |
| 0.34s | KPI 右（COST EST.） | 上浮 8px→0 + 淡入（180ms） |
| 0.40s | 桶行 · 未缓存输入 | 上浮 8px→0 + 淡入（170ms） |
| 0.45s | 桶行 · 输出 | 同上 |
| 0.50s | 桶行 · 缓存读取 | 同上 |
| 0.55s | 桶行 · 缓存写入 | 同上 |
| 0.40s | 四条进度条（与桶行并行） | 宽度 0→目标占比（300ms，线性） |
| 0.48s | 环轨（底圈） | 透明度 0→1（140ms） |
| 0.54s | 环弧 · 蓝（未缓存输入 38%） | 描边自起点生长至约 137°（360ms，线性） |
| 0.62s | 环弧 · 绿（输出 28%） | 生长至约 101°（320ms） |
| 0.70s | 环弧 · 紫（缓存读取 22%） | 生长至约 79°（280ms） |
| 0.76s | 环弧 · 橙（缓存写入 12%） | 生长至约 43°（230ms） |
| 0.54s | 环心大数字 | 0 递增至目标总量（设计稿参考值 742.6K）（440ms，缓出，末位直接落位不滚动小数位） |
| 0.60s | 环心副标（TOKENS · LAST 30 DAYS） | 淡入（160ms） |
| 0.72s | 日均 sparkline | 路径自左端按点序描出（380ms，线性）；描线结束后填充区淡入（120ms） |
| 0.78s | 峰值标注 44.6K | 淡入（150ms） |
| 0.78s | TOP 3 三行 | 依次上浮 8px + 淡入，行间错峰 40ms |
| 0.86s | ALERTS 胶囊 ×3 | 自右轻滑 12px + 淡入（200ms）；`RATE LIMITED` 项追加一次描边脉冲后静止 |
| 0.92s | 按钮组（COPY JSON / EXPORT CSV / RESET STATS） | 淡入至约 60% 不透明度（180ms），保持最弱存在感 |
| 0.98s | 底栏状态行 | 淡入（180ms） |

**要点**

- 四色弧**按蓝→绿→紫→橙顺序**依次描边生长，彼此有约 80ms 重叠，视觉上是一条连贯的环在画。
- 环轨必须**先于**色弧出现（0.48s vs 0.54s），否则色弧像凭空出现。
- 环心数字与色弧**同时起跑**（均 0.54s），数字先到位（0.98s）而环刚好画完（0.99s），两者收在同一拍。
- sparkline / TOP3 / ALERTS / 按钮组属于**宽版加项**，紧凑版没有，不出现在紧凑版的编排里。

### 2.2 紧凑版（360×800 / 400×520）

总时长 ≈1.0s，**定格点：1.0s**。步骤合并，但**不删内容**。

| 时间 | 元素 | 变化 |
|------|------|------|
| 0.00s | 外框 + 四角角标 | 透明度 0→1 + 缩放 0.98→1.00（200ms） |
| 0.08s | 品牌头（DSH CmdKit / Usage · Commands）、右上 Usage \| Commands 切换器、主视图 Tab、时间窗药丸 | **合并为同一组**，整体上移 6px→0 + 淡入（200ms） |
| 0.24s | KPI 左 / 右 | 上浮 8px→0 + 淡入（170ms，两枚间错峰 40ms） |
| 0.30s | 环轨 | 透明度 0→1（130ms） |
| 0.34s | 环弧 · 蓝 | 描边生长 160ms |
| 0.37s | 环弧 · 绿 | 描边生长 150ms |
| 0.40s | 环弧 · 紫 | 描边生长 140ms |
| 0.43s | 环弧 · 橙 | 描边生长 130ms（0.56s 四色合拢） |
| 0.34s | 环心大数字 | 0 递增至目标总量（400ms，缓出） |
| 0.42s | 环心副标 | 淡入（150ms） |
| 0.36s | 桶行 ×4 | 依次上浮 8px + 淡入，行间错峰 45ms（0.72s 收） |
| 0.36s | 四条进度条（并行） | 宽度 0→目标占比（260ms，线性） |
| 0.74s | 洞察文案 | 淡入（180ms） |
| 0.82s | ⌘K 入口条 | 淡入 + **一次性极轻上跳**（约 3px 后回落，200ms），用于提示「还有另一面」 |
| 0.90s | 底栏状态行 | 淡入（160ms） |

**要点**

- 紧凑版的环**比宽版小**（360 档环径 252 / 400 档 158），色弧动画时长也要相应压短，否则显得拖沓。
- 环在紧凑版**先于**列表行出现（0.34s vs 0.36s）——窄栏里环是主角，读数是配角。
- 紧凑版**没有** sparkline / TOP3 / ALERTS / 按钮组，也不做这些元素的入场动作（元素不存在，动效不存在）。

## 3. Commands 命令面板

### 3.1 唤出（⌘K / Ctrl+K）

| 时间 | 元素 | 变化 |
|------|------|------|
| 0.00s | 背景遮罩 | 透明度 0→30%（150ms） |
| 0.02s | 面板本体 | 自「中心偏上」定位，缩放 0.96→1.00 + 淡入（160ms，缓出） |
| 0.06s | 搜索框 | **立即获得焦点**；输入框边框亮度微升一次后回落（120ms） |
| 0.08s | 列表首项 | 默认选中：左侧亮条 0→满高 + 底色淡入（120ms） |
| 0.10s | 其余命令行 | 依序淡入，行间错峰 30ms；**列表超过 8 项时只淡入前 8 项，其余直接呈现** |

**要点**

- 面板的锚点是**中心偏上**，不是正中——正中会让它压住输入框视线。
- 遮罩只到 30%，**不遮死底下的 Usage 侧栏**。

### 3.2 输入过滤

| 时间 | 元素 | 变化 |
|------|------|------|
| 0.00s | 命中的新项 | 淡入（140ms） |
| 0.00s | 落选的旧项 | 淡出（120ms） |
| 0.00s | 列表容器 | 高度折叠到新高度（150ms，缓出） |

**要点**

- 交叉淡入淡出，**行间距保持不变**；列表容器高度变化要平滑，**不得抖动**。
- 过滤结果为空时，列表区收成一个居中的空态提示，提示淡入 140ms。

### 3.3 键盘导航与执行

| 动作 | 表现 |
|------|------|
| ↑ / ↓ 移动 | 高亮条平移到新行（120ms，缓出），**无弹跳、无回弹** |
| Enter 执行 | 选中行整体亮度 +10% 闪一下（80ms）作为确认，随即走关闭序列 |
| Tab / Shift+Tab | 与 ↑↓ 同规格 |

### 3.4 关闭（Esc / 点击遮罩 / 执行后）

| 时间 | 元素 | 变化 |
|------|------|------|
| 0.00s | 面板本体 | 缩放 1.00→0.98 + 淡出（120ms） |
| 0.06s | 背景遮罩 | 透明度 30%→0（140ms） |

**要点**

- 关闭比唤出**略快**（120ms vs 160ms），收得干脆。
- 面板关闭后，焦点回到唤出前的位置（搜索框或触发元素）。

### 3.5 与 Usage 侧栏的共存

- 唤出 Commands 时，**Usage 侧栏不卸载**，只做 5–8% 的压暗（180ms）。
- 关闭后压暗恢复（160ms）。
- 唤出前侧栏正在进行的入场动画**不被打断**，也不重播。

## 4. 微交互（全程可用，入场结束后同样生效）

| 触发 | 元素 | 变化 |
|------|------|------|
| 切换主视图 Tab | 下划线 / 实心底 | 横向平移 150ms（缓出） |
| 切换主视图 Tab | 内容区 | 淡切 160ms，**不整页翻页** |
| 切换时间窗 TODAY / 7 DAYS / 30 DAYS | 选中药丸 | 底色横向平移 150ms；数值区淡切 160ms |
| 切换 Usage \| Commands（窄屏） | 两侧内容 | 横向滑切 12–16px + 淡入淡出，200ms |
| 按钮 hover | 边框 + 文字 | 亮度微升，120ms |
| 按钮按下 | 按钮本体 | 下压 1px（80ms），松开回弹 120ms |
| 告警胶囊出现 | 胶囊 | 自右滑入 12px + 淡入 200ms；严重项追加**一次**描边脉冲后静止 |
| `synced` 状态点 | 底部小点 | 极慢闪烁（周期 ≥2s）或常亮，**不得抢主视觉** |
| 环心柔光 | 环外光晕 | 3–5s 周期极慢呼吸，亮度 ±5% 内 |

## 5. 数据刷新与插值

| 场景 | 变化 |
|------|------|
| 刷新后四桶数值变化 | 进度条宽度从旧值平滑插值到新值，300–500ms，**禁止瞬间跳变** |
| 刷新后环占比变化 | 四色弧角度平滑插值到新角度，300–500ms，色弧**不重播**入场生长动画 |
| 刷新后环心数字变化 | 数字递增/递减到新值，300–500ms，缓出 |
| 刷新后 KPI / 洞察文案 | 淡切 160ms，不做数字滚动以外的动作 |
| 刷新指示 | 底部状态行做一次极轻的亮度脉冲（80ms）提示「已更新」 |

**要点**：刷新是数据变化，**不是重新入场**。首次入场的编排动画只在面板首次挂载时跑一次，之后刷新只走插值。

## 6. 多分辨率注意事项

### 6.1 编排合并

- **360 / 400（紧凑档）**：入场步骤合并为「框 → KPI + 列表 → 环」，总时长仍 ≤1.0s。⌘K 入口条可单独轻跳提示一次。
- **720 / 1280（宽版）**：先跑完 Usage 入场约 60%（到约 0.70s），再叠 Commands 唤出动效。**这条只用于演示片**；日常使用中 Commands 仅在按键时出现，与 Usage 入场无先后关系。

### 6.2 各档实际出现的场景

宿主右栏是**始终全高**的竖条，宽度随视口按比例变化；**720 / 1280 这两档的宽扁比例在停靠状态下不会出现，只出现在全屏模式**。因此：

| 档 | 静止画布 | 真实出现场景 | 入场节奏 |
|---|---|---|---|
| A | 360×800 | 停靠右栏拖到最窄 / 小窗口 | 紧凑版编排（≤1.0s） |
| B | 400×520 | 停靠右栏拖窄 / 概览卡片 | 紧凑版编排（≤1.0s） |
| C | 720×420 | **全屏**于小窗口 | 宽版编排 |
| D | 1280×720 | **全屏**于常规桌面 | 宽版编排 |

日常停靠右栏的宽度会随窗口变化，**因此断点要按「面板实测宽度」判定，不按窗口宽度判定**。

### 6.3 元素级的分辨率差异

- **环形外侧百分比标签**（38% / 28% / 22% / 12%）**只在 A 档与 D 档存在**，B 档与 C 档的环上没有外标签——这两档**不做标签生长动效**，环只表达总量与配比。
- **品牌头**：A 档在左上，副标题即 `Usage · Commands`；B / C 档左上只留 `DSH CmdKit`，切换器统一提到右上；D 档顶栏右侧换成 **⌘K 芯片**，`Usage | Commands` 切换器下移到左列标题旁。品牌头、切换器与 ⌘K 芯片**各自的出现方式保持一致**：都是淡入 + 6px 上移，不因位置变化而换动作。
- **⌘K 芯片**只出现在 D 档，是全屏下唯一的全局命令入口。它本身不参与入场编排的额外动作——芯片的亮起只发生在**键盘唤出**时，走 §3 的面板时序。
- **sparkline 填充区**只在 D 档存在（宽版加项），描线结束后才淡入，不能与描线同时进行。

## 7. 静帧定格对照

出静帧时只表现**入场结束后的稳定态**；若需标注，写「**入场 1.15s 后定格**」（紧凑档写「入场 1.0s 后定格」）。

| 静帧 | 对应编排 | 定格标注 |
|------|----------|----------|
| `dsh-cmdkit-v4-360x800.png` | 紧凑版 | 入场 1.0s 后定格 |
| `dsh-cmdkit-v4-400x520.png` | 紧凑版 | 入场 1.0s 后定格 |
| `dsh-cmdkit-v4-720x420.png` | 宽版（Usage 侧栏部分已定格） | Usage 入场 1.15s 后定格；命令面板为**唤出瞬间**（0.08s，选中首项、其余已淡入） |
| `dsh-cmdkit-v4-1280x720.png` | 宽版 | Usage 入场 1.15s 后定格；命令面板为**唤出瞬间**（0.08s） |

**注意**：命令面板相关的两档静帧刻画的是「刚唤出」的状态（搜索框已聚焦、首项已高亮、遮罩已上），**不是**入场结束后的静止态——面板本身没有「入场结束」这一说，它是被唤出后即静止。

## 8. 禁止清单

- ❌ 粒子雨 / 粒子场 / 满屏星点
- ❌ 强闪烁、频闪、瞬时亮度跳变
- ❌ 无限循环的装饰性动画（除 §0 允许的呼吸与状态点）
- ❌ 准星、扫描线、MISSION 式大标题动画
- ❌ 60FPS 全量刷新的逐帧重绘感
- ❌ 标题做难读的双色渐变
- ❌ 四色出现在环段、进度条与图例文字**以外**的地方；正文一律中性灰阶
- ❌ 数字滚动越过终值再回弹、进度条回缩、列表抖动
- ❌ 同屏超过 8 项元素连续跳动
